# Automatización DIAN y procesamiento de facturas

Proyecto en Python para consultar documentos electrónicos en la DIAN, descargar facturas PDF y extraer datos estructurados con soporte OCR.

Consulta la [documentación completa](README-pdf.md) para conocer los requisitos, los comandos y las pruebas.

Los archivos de entrada, las facturas, los resultados, los logs y los perfiles del navegador se mantienen localmente y están excluidos de Git.

Antes de ejecutar el flujo, prepara `data/input/cufes.csv` siguiendo el formato descrito en la documentación.
